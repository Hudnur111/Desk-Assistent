# 🧠 Gehirn - Knowledge Management System

Professionelle digitale Wissensverwaltung mit Obsidian.

## 📂 Struktur

- **00-Inbox**: Schnelle Notizen & tägliche Erfassungen
- **01-MOCs**: Maps of Content - Übersichtsseiten
- **02-Archive**: Archivierte/verworfene Inhalte
- **03-Templates**: Vorlagen für Notizenerstellung
- **04-Resources**: Ressourcen, Links, externe Referenzen

## 🚀 Start

1. `.obsidian/` Ordner in Obsidian öffnen
2. Vault wird automatisch initialisiert
3. Tägliche Notizt in `00-Inbox` starten

## 📝 Workflow

- Inbox → Process → Archive
- Bidirektionale Links nutzen
- Tags für Kategorisierung: `#topic/subtopic`
