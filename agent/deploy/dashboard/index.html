Über dieses System

Jarvis Desk-Assistant
Autonomer Assistent auf Basis der Anthropic-API. Laeuft als jarvis.service (systemd), startet automatisch bei Boot und nach Abstuerzen neu (Restart=always).
Dieses Dashboard
Wird direkt vom Pi ueber jarvis-status.service ausgeliefert (Port 8090) - erreichbar von jedem Geraet im selben Netz, ohne dass ein anderer Rechner laufen muss. Aktualisiert sich alle 3 Sekunden selbst.
Auto-Update
jarvis-update.timer prueft alle 90s per git fetch auf neue Commits (oeffentliches Repo, kein Token noetig) und deployt automatisch. Schlaegt der Neustart fehl, rollt das Update selbststaendig auf den letzten funktionierenden Commit zurueck.
Gehaeuse-Luefter
Fest an 5V/GND angeschlossen (nicht GPIO-geschaltet) - laeuft dauerhaft mit voller Drehzahl, sobald der Pi Strom hat. Keine Software-Steuerung noetig.
Steuerung (An / Ruhemodus / Aus)
An startet jarvis.service, Ruhemodus stoppt nur den Assistenten (Pi und Dashboard bleiben erreichbar), Aus fährt den ganzen Pi herunter - danach nur noch per physischem Stromstecker wieder einschaltbar. Diese Knöpfe sind bewusst nicht durch ein Passwort geschützt: jedes Gerät im selben Netzwerk kann sie auslösen. Jede Aktion wird protokolliert (data/control-history.jsonl).
