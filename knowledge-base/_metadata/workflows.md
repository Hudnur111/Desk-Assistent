# 🔄 Workflows & Automationen

## Daily Workflow

```
08:00 - Morning Review
  → Check Daily Note
  → Review Top 3 Priorities
  
Throughout Day
  → Capture ideas in Inbox
  → Update progress
  
18:00 - Evening Reflection
  → Reflect on day
  → Log learnings
  → Set tomorrow priorities
```

## Weekly Workflow

**Every Sunday**

```
1. Review all Inbox items (15 min)
   → Move to appropriate categories
   → Delete/Archive what's not needed

2. Update Projects status (20 min)
   → Check deadlines
   → Update progress
   → Identify blockers

3. Review Areas (15 min)
   → Assess progress toward goals
   → Update notes

4. Create next week Daily Notes (5 min)
```

## Monthly Workflow

**First Sunday of Month**

```
1. Archive completed projects
2. Review and update Areas
3. Clean up Resources
4. Review learning progress
5. Plan next month focus areas
```
