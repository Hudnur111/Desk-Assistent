# 🏷️ Tag-Hierarchie

## Struktur: `category/subcategory`

### Domains
- `dev/` - Entwicklung & Engineering
- `design/` - Design & UX
- `business/` - Strategie & Business
- `learning/` - Wissen & Entwicklung
- `meta/` - System & Prozesse

### Dev-Tags
- `dev/frontend`
- `dev/backend`
- `dev/devops`
- `dev/database`
- `dev/architecture`

### Learning-Tags
- `learning/language` (Programmiersprachen)
- `learning/framework` (Frameworks)
- `learning/tool` (Tools)
- `learning/pattern` (Design Patterns)

### Status-Tags
- `status/todo`
- `status/inprogress`
- `status/done`
- `status/blocked`

### Priority-Tags
- `priority/high`
- `priority/medium`
- `priority/low`

## Anwendung

Jede Note sollte 2-4 Tags haben:
```yaml
tags: [dev/backend, learning/architecture, priority/high]
```

## Navigation über Tags

- Tag-Pane nutzen (Rechts)
- Filter kombinieren für Fokus
- Regelmäßig Tag-Struktur überprüfen
