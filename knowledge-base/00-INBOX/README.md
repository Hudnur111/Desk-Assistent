# 📥 Inbox

Triage-Punkt für alle neuen Inhalte.

## Workflow

```
Capture → Review → Classify → Archive/Move
```

## Processing

1. **Tägliche Verarbeitung** - Notizen einordnen
2. **Wöchentliche Archivierung** - Inbox leeren
3. **Maximal 20 Notes** in Inbox gleichzeitig

## Struktur

```
00-INBOX/
├── Daily-YYYY-MM-DD.md
└── Quick-Captures/
```

Neue Notes gehören hier hin, werden dann klassifiziert.
